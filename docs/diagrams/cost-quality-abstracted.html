Cost vs. quality on one repository — by model class

Mean judge score against mean cost per task, 19 models over 21 software-engineering tasks in a single repository. Model names are abstracted to their class: closed-source models by tier, open-weight models by architecture.

What is abstracted. Only the model names. Every score, cost and position is the measured value from the run. A closed-source point is named by its tier and generation; an open-weight point by parameter count and dense/MoE architecture, since that is what determines the hardware it needs.
Cost basis — the two colours are not one currency. A closed-source point is a metered per-token bill. An open-weight point is hardware-derived: the GPU instance's hourly rate divided by measured throughput at a stated concurrency. Compare within a colour; across colours the comparison is directional only. Scores come from one repository and one run per task, so treat the ordering as more portable than the absolute numbers.
